# Будущие фотографии

Позже положите сюда: `hero.jpg`, `interior-01.jpg`, `interior-02.jpg`, `hedgehog-01.jpg`, `hedgehog-02.jpg`, `event-01.jpg`, `event-02.jpg`, `og-cover.jpg`.

До появления оригинальных материалов интерфейс использует CSS-заглушки и не создаёт сломанных изображений.

После загрузки файлов укажите их публичные пути только в `src/config/media.ts`.
Компонент `Media` сам покажет изображение вместо соответствующей заглушки.
